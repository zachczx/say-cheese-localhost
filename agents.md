# Agent Guidelines

## Git Commit Conventions

- Use [Conventional Commits](https://www.conventionalcommits.org/) (e.g., `feat: ...`, `fix: ...`, `chore: ...`, `docs: ...`, `refactor: ...`, `test: ...`).
- **No scope**: Do not include scopes in commit messages. Use `<type>: <description>` format without parentheses (e.g., use `feat: add feature` instead of `feat(scope): add feature`).
